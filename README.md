# Webbgrunder för ITE130

> För nya studenter i Interaktiva användargränssnitt.

## CSS-klasser

Klassen kopplas till HTML-elementet.

```html
<p class="intro">Hej!</p>
```

```css
.intro {
  color: #eef2ff;
  background: #1a2233;
}
```

## Bootstrap-grid

En rad delas i två lika stora kolumner.

```html
<div class="row">
  <div class="col-md-6">Vänster</div>
  <div class="col-md-6">Höger</div>
</div>
```

## Vibe coding

- Beskriv målet.
- Ange färger och layout.
- Lägg till en ändring i taget.
- Testa i webbläsaren.
